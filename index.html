quantum_gates.py
Quantum gates as NumPy matrices (complex128). Single- and two-qubit gates.

Gates.Rx(θ), .Ry(θ), .Rz(θ), .P(φ)
Gates.CNOT, .CZ, .SWAP

quantum_math.py
Quantum linear algebra: states, density matrices, Von Neumann entropy, fidelity.

.bloch_vector(state)
.density_matrix(state)

⚙ Quick Installation

Choose your preferred environment manager.

# Create environment and activate
conda env create -f environment.yml
conda activate quantum-book

# Launch JupyterLab
jupyter lab
# Install dependencies
pip install -r requirements.txt

# Launch JupyterLab
jupyter lab
🧪 Run Tests
pytest tests/ -v
