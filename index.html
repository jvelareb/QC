🔩 Módulos src/

Bibliotecas reutilizables de álgebra cuántica y visualización.

🚪
quantum_gates.py
Puertas cuánticas como matrices NumPy (complex128). Incluye puertas de 1 y 2 qubits.
Gates.H, .X, .Y, .Z, .S, .T
Gates.Rx(θ), .Ry(θ), .Rz(θ), .P(φ)
Gates.CNOT, .CZ, .SWAP
Gates.tensor(*gates)
∫
quantum_math.py
Álgebra lineal cuántica: estados, matrices de densidad, entropía de Von Neumann, fidelidad.
QuantumMath.ket0(), .ket_plus()
.bloch_vector(state)
.density_matrix(state)
.von_neumann_entropy(rho)
🌐
bloch_simulator.py
Simulador interactivo de esfera de Bloch con trayectorias 3D y widgets Jupyter.
BlochSimulator(initial_state)
.apply_gate(gate)
.plot_3d()
.apply_sequence([gates])
📊
visualization.py
Visualizaciones unificadas con estilo dark academic. Histogramas, Bloch sphere, heatmaps.
QuantumVisualization.histogram(counts)
.bloch_sphere(state)
.gate_heatmap(U)
.statevector(sv)
📚 Documentación

Guías de instalación, arquitectura y referencia.

⚙ Instalación Rápida

Elige tu gestor de entornos preferido.

# Crear entorno y activar
conda env create -f environment.yml
conda activate quantum-book

# Iniciar JupyterLab
jupyter lab
# Instalar dependencias
pip install -r requirements.txt

# Iniciar JupyterLab
jupyter lab
# Ir al directorio H2
cd H2

# Crear entorno virtual dedicado
python -m venv .venv_h2
.venv_h2\Scripts\activate   # Windows
# source .venv_h2/bin/activate  # Linux/Mac

# Configurar entorno
python setup_h2_env.py

# Abrir notebooks H2
jupyter lab h2.ipynb
🧪 Ejecutar Tests
pytest tests/ -v
🧪 H₂ Lab — Simulación Molecular

Directorio especializado con simulaciones cuánticas de la molécula de hidrógeno (H₂), incluyendo curvas de disociación con VQE y circuitos QAOA.

h2.ipynb
Simulación principal de la molécula H₂. Curva de disociación y energía del estado base.
📓
qaoa.ipynb
QAOA aplicado al problema H₂. Circuitos plegado y lineal para k=6.
